## Recording Guidelines

1. **Resolution:** 1920x1080 (16:9).
2. **Audio:** Clear vocal track, 0.0dB peak normalization, optional subtle ambient trail wind sound effect in background.
3. **Pacing:** ~135 words per minute (crisp, professional, authoritative). Total script length: 142 words.
4. **No Fluff:** Never show empty terminal windows or long code scroll sessions; every second features the running product and TabPFN value proposition.
